Interpretation

What the experiment suggests

01

Loss choice materially changed probability quality

Label smoothing and focal loss sharply reduced common evaluation loss and perplexity versus standard cross entropy.

02

Label smoothing improved NLL more than accuracy

The result is consistent with better-calibrated confidence rather than a large shift in top-1 token predictions.

03

Focal loss gave the strongest balanced profile

It achieved the highest overall token accuracy and the lowest answer-only evaluation loss while keeping perplexity low.

04

2× answer weighting only marginally changed answer accuracy

It had the highest answer-token accuracy by a tiny margin, but overall likelihood metrics remained close to the CE baseline.

05

Next step: replicate across seeds

These are single-seed results. Stronger evidence requires repeated runs and an untouched final holdout set.

Important: raw training loss is not directly comparable across different loss functions. All dashboard comparisons use the common post-training evaluator.
